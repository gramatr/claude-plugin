# grāmatr — Claude Code plugin

Patent-pending intelligence layer for every AI tool you use. Decision routing that makes every prompt cheaper, faster, and aware of what came before.

## Install

```
/plugin marketplace add gramatr/claude-plugin
/plugin install gramatr@gramatr
```

## What this repo is

This is a **mirror** generated by the release workflow in
[`gramatr/gramatr`](https://github.com/gramatr/gramatr) on every tagged release.
The contents are pushed verbatim from `dist/marketplace/claude-plugin/`.

**Do not contribute here.** PRs should be opened against
[`gramatr/gramatr`](https://github.com/gramatr/gramatr). Bug reports go to
[`gramatr/gramatr/issues`](https://github.com/gramatr/gramatr/issues).

## Plugin contents

- `.claude-plugin/marketplace.json` — Anthropic marketplace catalog
- `.claude-plugin/plugin.json` — plugin manifest
- `.mcp.json` — HTTPS transport pointing at `api.gramatr.com/mcp`
- `hooks/hooks.json` — `mcp_tool` hooks invoking server-side tools (UserPromptSubmit, SessionEnd, Stop)

The plugin install is structurally hermetic: a fresh install produces zero files outside `~/.claude/plugins/cache/gramatr/<version>/`.
